# Evidencias

Carpeta destinada a las capturas y salidas de consola tomadas durante la ejecución real de los
tres sistemas.

## Organización

```
evidencias/
├── caso1/   # Préstamos de equipos (puerto 8001)
├── caso2/   # Consultas médicas (puerto 8002)
└── caso3/   # Asistencia y permisos (puerto 8003)
```

## Convención

- Nombre: `NN_descripcion.png` (ejemplo `01_login.png`).
- Incluir la URL visible y el nombre del sistema.
- No mostrar contraseñas ni datos personales reales.
- Guardar las salidas de pruebas como `pruebas_consola.txt`.
- Cada imagen debe tener un pie de figura en el informe.
